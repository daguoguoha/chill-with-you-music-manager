# Chill 音乐插件管理器 v1.4.0-rc.1

六平台歌词与启动续播合集。[下载完整一键包](https://github.com/daguoguoha/chill-with-you-music-manager/releases/tag/v1.4.0-rc.1)，选择 **ChillMusicManager-1.4.0.zip**。完整解压后双击管理器，退出游戏，仅对需要的平台执行“安装 / 修复”。只用网易云就只操作网易云一行。

## 底部歌词

歌词默认显示在画面下方、游戏原生播放器上方，背景完全透明，没有底板或装饰线；当前句和下一句均自动换行并按内容增高，画面只显示歌词，不显示平台名称、LYRICS 标题或设置/隐藏按钮；保留游戏风格的浅色文字和轻微文字阴影。

- **V**：显示或隐藏当前平台歌词。长按只切换一次；游戏不在前台、正在输入内容或使用 Ctrl/Alt/Shift 组合键时不触发。
- **拖动歌词正文**：改变显示位置，松开鼠标后保存；重启和调整窗口大小后保留相对位置。歌词设置中的“重置位置”恢复底部中央。
- **平台歌单面板中的“歌词设置”**：调整字号、同步偏移、颜色和位置。提供白、浅紫、浅蓝、粉、薄荷、暖黄预设，也可输入 `#RRGGBB` 自定义颜色。
- **LRC 导入**：先播放目标音频，在歌词设置中粘贴本机 `.lrc` / `.txt` 路径，或粘贴歌词文本，再点“导入歌词”。粘贴框非空时优先使用粘贴内容。
- 支持标准 LRC、多时间戳、毫秒、offset、同时间翻译行、UTF-8 / UTF-16 / GB18030。没有时间轴的文本会明确显示“无时间轴”。
- 网易云和 QQ 自动获取公开歌词；酷狗按音频 hash 查询歌词，接口不可用时仍可导入 LRC。B站、喜马拉雅使用 LRC 导入；椒盐同时自动读取音频旁的同名 `.lrc`。
- 收起歌单面板后歌词仍显示。暂停、拖动进度、上一首/下一首与选歌跟随游戏实际音频位置；快速切歌会丢弃旧曲目的迟到响应。

歌词缓存在 `BepInEx/config/ChillLyrics/<平台>/`，只保存在本机。配置在原平台配置文件的 `[Lyrics]` 节，不修改游戏存档。

## 启动继续上次播放

首次更新后正常播放一次，程序才会建立新的会话记录。之后启动游戏会在原登录可用、网络与音源权限允许时，恢复最后使用平台的歌单、曲目和实际播放位置，并保留上次播放/暂停状态。每 5 秒及暂停、拖动、切歌、失去焦点、正常退出时保存。

六个平台共用 `BepInEx/config/ChillPlaybackSession/last.json`，只由最近播放的平台恢复，避免多个平台争抢播放器。记录包含本地曲目元数据、最多 2000 个队列条目、进度、播放状态和更新时间，不包含登录 Cookie 或 Token，不上传网络。更新、停用和撤回保留该目录。

上次播放的是游戏原音乐时，保留游戏自身的播放行为；如果你在启动期间已经选了其他平台的音频，不再覆盖你的选择。切换账号会取消待恢复操作。播放不足 3 秒、接近结尾或音频时长明显变化时从头开始；缺少原登录/本地文件/音源权限时可手动选择歌单。

平台配置 `[Resume] RestoreLastSession = false` 可关闭启动恢复。原“音频进度保存”插件仍提供各音轨的历史进度，新会话恢复补上了启动时的歌单和曲目重载。

快捷键保持 F8 网易云、F9 QQ、F10 酷狗、F11 B站、F7 喜马拉雅、F6 椒盐。V 仅切换当前播放平台的歌词。原安装、停用、重新启用、修复与撤回功能保留；账号、歌词、会话、配置、音频进度与游戏存档保留。

首次安装阶段完全离线；联网平台的歌词、登录与播放仍需网络和原账号权限。候选版不替换稳定 Latest。验证与限制见 `TESTING.md`，旧版完整说明见 `PREVIOUS_VERSION_README.md`。

管理器和插件源码随包提供，使用 `Build.ps1` 和各平台 `Build.ps1 -GameDirectory <游戏目录>` 构建。GitHub Source code 不包含完整离线依赖，请用 Release 完整包作为安装器。管理器 GPL-3.0-or-later，第三方项目保留各自许可证。
