# Chill 音乐插件管理器 v1.6.1-rc.1

[下载完整一键包](https://github.com/daguoguoha/chill-with-you-music-manager/releases/tag/v1.6.1-rc.1)，选择 **ChillMusicManager-1.6.1-rc.1.zip**。完整解压后退出游戏，双击 `ChillMusicManager.exe`，只给需要的平台执行“安装 / 修复”。GitHub 的 Source code 压缩包仅用于查看源码，安装请使用 Release 完整包。

本次修复网易云在不同电脑上的播放兼容性。网易云模块升级为 **1.5.1**：MP3 改用随包 NLayer 解码，不依赖 Windows Media Foundation/ACM；新接口连接异常时会尝试备用接口；音频下载最多尝试三次，每次重取播放地址；失败日志区分取地址、下载、解码和创建音频，并记录状态码。长音轨使用本地 PCM 文件，减少内存峰值。

更新时正常退出游戏，完整解压本包，打开管理器，选择网易云执行“安装 / 修复”。不要只复制 DLL，新增的 NLayer.dll 必须一同安装。保留账号、歌词和续播记录；如需回退可使用管理器“撤回”。本次仍为候选版；FLAC/AAC/M4A 仍使用系统媒体组件，未在真实 Windows N 环境和反馈用户电脑上完成验收。详见 [PLAYBACK_FIX.md](PLAYBACK_FIX.md)。


此次新增网易云、酷狗、B站、喜马拉雅、椒盐的底栏红心；位置与大小跟随原生循环按钮。平台面板的歌曲行和当前播放区域也提供红心。图标先读取真实状态，点击后提交并重新读取确认；请求失败不会假装成功，不自动重试写入。切换账号清除旧状态。

**本候选包暂不包含 QQ 模块。** 此前重建的 QQ 桥接被卡巴斯基检测为 `VHO:Backdoor.Win32.Androm.gen`，不能将该告警视为误报。本次没有读取、运行、重建或打包该文件；也不会恢复隔离文件、添加排除项或关闭保护。此包不会自动删除用户已有的 QQ 插件；如已有安全软件告警，请按安全软件指引处理。

网易云和酷狗增加“每日推荐”入口，点击读取并送入游戏原生列表。推荐内容、登录、音源与账号权限由平台决定。酷狗和喜马拉雅的红心目前不能保证账号同步，请先查看各平台 HEART_TESTING.md。

保留原生列表、上一首/下一首、暂停、进度、播放失败跳曲、真实播放记录、透明歌词、V 键隐藏、拖动歌词位置、颜色设置、LRC 导入与启动续播。详见 [LYRICS_AND_RESUME.md](LYRICS_AND_RESUME.md) 和 [PLAYBACK_SPEED.md](PLAYBACK_SPEED.md)。歌词自动来源依平台能力而定，B站与喜马拉雅使用 LRC 导入。

首次安装完全离线；平台功能仍需联网。安装、停用和撤回保留账号、歌单、歌词、配置、播放会话和游戏存档。不含用户账号、Cookie、私有收藏、私人插件或游戏文件。

源码与构建脚本随包提供。管理器和插件使用 GPL-3.0-or-later，第三方项目及各自许可证见每个平台的 THIRD_PARTY_NOTICES.md 与 licenses/。网易云原生桥接对应源码在 packages/netease/native-source/ChillNetease-source.zip 中。本候选版不替换稳定 Latest；验证边界见 [TESTING.md](TESTING.md)。
