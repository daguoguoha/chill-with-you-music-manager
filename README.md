# Chill 音乐插件管理器 v2.0.2

[下载完整一键包](https://github.com/daguoguoha/chill-with-you-music-manager/releases/tag/v2.0.2)，选择 **ChillMusicManager-2.0.2.zip**。完整解压后退出游戏，双击 `ChillMusicManager.exe`，只给需要的平台执行“安装 / 修复”。GitHub 的 Source code 压缩包仅用于查看源码，安装请使用 Release 完整包。

**2.0.2 新增网易云完整 MP3 边下边播及五平台退出缓存清理。** 缓冲约 8 秒即可开播，缓冲等待、拖动和手动暂停接入游戏原生播放器。退出释放音频临时文件，启动补清异常残留；保留歌词、账号及本地源音乐。详见 [STREAMING_AND_CACHE.md](STREAMING_AND_CACHE.md)。同时修正网易云网络失败后连续跳曲，并保留底层连接错误分类。 播放地址请求有了明确超时和大小限制，音频改为后台系统下载，慢网时限随文件大小调整，面板显示下载进度，错误报告已集成，无需另装旧诊断补丁。详见 [NETWORK_RECOVERY.md](NETWORK_RECOVERY.md)。

**2.0.1新增可选歌词翻译**。在平台面板打开“歌词设置”，将“翻译”切为开，原文保持在上方、译文显示在下方。网易云优先读取平台中文译文；其他平台支持导入同时间轴翻译LRC。译文独立缓存，不覆盖原文，默认关闭，不使用额外机器翻译服务。详见 [LYRIC_TRANSLATION.md](LYRIC_TRANSLATION.md)。

本次2.0大更新统一修复五平台随机播放：左侧保留歌单顺序，实际随机切歌并定位当前行，切换歌单保留随机模式；同步 MP3 托管解码、长音轨内存控制，并为酷狗、B站、喜马拉雅补齐音频下载重试和错误分类。保留网易云扫码诊断修复。网易云/酷狗优先高码率MP3，五平台使用32位浮点中间缓冲，见[AUDIO_QUALITY.md](AUDIO_QUALITY.md)。更新保留账号、歌词、歌单和续播记录，详见 [PLATFORM_SYNC.md](PLATFORM_SYNC.md)。

此前已提供网易云、酷狗、B站、喜马拉雅、椒盐的底栏红心；位置与大小跟随原生循环按钮。平台面板的歌曲行和当前播放区域也提供红心。图标先读取真实状态，点击后提交并重新读取确认；请求失败不会假装成功，不自动重试写入。切换账号清除旧状态。

**本候选包暂不包含 QQ 模块。** 此前重建的 QQ 桥接被卡巴斯基检测为 `VHO:Backdoor.Win32.Androm.gen`，不能将该告警视为误报。本次没有读取、运行、重建或打包该文件；也不会恢复隔离文件、添加排除项或关闭保护。此包不会自动删除用户已有的 QQ 插件；如已有安全软件告警，请按安全软件指引处理。

网易云和酷狗增加“每日推荐”入口，点击读取并送入游戏原生列表。推荐内容、登录、音源与账号权限由平台决定。酷狗和喜马拉雅的红心目前不能保证账号同步，请先查看各平台 HEART_TESTING.md。

保留原生列表、上一首/下一首、暂停、进度、播放失败跳曲、真实播放记录、透明歌词、V 键隐藏、拖动歌词位置、颜色设置、LRC 导入与启动续播。详见 [LYRICS_AND_RESUME.md](LYRICS_AND_RESUME.md) 和 [PLAYBACK_SPEED.md](PLAYBACK_SPEED.md)。歌词自动来源依平台能力而定，B站与喜马拉雅使用 LRC 导入。

首次安装完全离线；平台功能仍需联网。安装、停用和撤回保留账号、歌单、歌词、配置、播放会话和游戏存档。不含用户账号、Cookie、私有收藏、私人插件或游戏文件。

源码与构建脚本随包提供。管理器和插件使用 GPL-3.0-or-later，第三方项目及各自许可证见每个平台的 THIRD_PARTY_NOTICES.md 与 licenses/。网易云原生桥接对应源码在 packages/netease/native-source/ChillNetease-source.zip 中。本候选版不替换稳定 Latest；验证边界见 [TESTING.md](TESTING.md)。


当前歌曲定位：切歌、打开左侧播放列表或列表重建时，按歌曲唯一标识定位正在播放的行；同名歌曲不会混淆。等待原生列表布局稳定后居中一次，不持续干预手动滚动。当前歌曲不在浏览歌单时保留浏览位置。


扫码专项：四平台直连/代理下生成、等待、取消和重新生成均通过。修复临时轮询失败仍显示旧二维码、网易云缓存用户误判，以及扫码影响原账号Cookie的问题。详见 [QR_LOGIN_FIX.md](QR_LOGIN_FIX.md)。


**错误报告**：打开管理器，扫描游戏目录，点击“导出错误报告”，选择ZIP保存位置。游戏运行时也能导出，把ZIP发给维护者即可。报告只包含结构化版本、完整性、环境和错误分类，不含原始日志、账号、Cookie、二维码密钥、歌曲信息或请求地址；不会自动上传。CLI可用 `Manager.ps1 -Action Export -GameDirectory <游戏目录> -OutputPath <报告.zip>`。详见 [ERROR_REPORT.md](ERROR_REPORT.md)。

**减少切歌/换歌单卡顿**：续播记录序列化与写盘移到后台，并合并连续保存；换歌单只重建一次目标列表，切歌定位不再强制重算整个界面。网络取址、下载和首次解码仍可能需要等待，详见 [PERFORMANCE.md](PERFORMANCE.md)。
