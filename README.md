# Chill 音乐插件管理器 v1.0.0

**[下载完整离线安装包](https://github.com/daguoguoha/chill-with-you-music-manager/releases/latest)**

GitHub 自动生成的 Source code 压缩包仅用于查看管理器源码，不包含六个平台的二进制和离线依赖。普通使用请下载 Release 中的 `ChillMusicManager-1.0.0.zip`。开发时可先完整解压发行包，再使用本仓库源码重建管理器。

在一个窗口里管理六款 Chill With You 音乐插件。完整解压压缩包，双击 **ChillMusicManager.exe**，选择游戏目录，再点击 **扫描 / 刷新**。

## 可以做什么

- 自动查找 Steam 游戏目录；有多份安装时由你选择。
- 显示随包版本、安装记录中的版本、启用或停用状态和面板快捷键。
- 安装或修复选中的平台，校验随包安装器、插件与离线依赖。
- 单独停用和重新启用插件。多个平台可以同时安装。
- 撤回该平台最近一次由管理器完成的操作，包括撤回安装、修复、启用和停用。
- 检查完整 ChillPatcher、重复插件 DLL、不同加载器、缺失的共享框架文件，以及游戏是否还在运行。

选中一行后操作。安装和修复使用压缩包内的版本，**不会查询线上更新，也不会覆盖安装记录中更新的版本**。如需新版本，应获取更新的管理器包或对应平台包。

## 使用顺序

1. 保存并正常退出游戏。
2. 完整解压管理器，保留 `packages`、`catalog.json` 和 `Manager.ps1`，不要只拿走 EXE。
3. 双击 EXE，选择包含 `Chill With You.exe` 和 `Chill With You_Data` 的游戏文件夹。
4. 扫描后选中音乐平台，点击 **安装 / 修复至随包版本**。安装阶段无需联网。
5. 从 Steam 正常打开游戏，按表中的快捷键。联网平台的登录、歌单和播放仍需联网，由你在游戏中使用自己的账号操作。

管理器显示的是文件检查结果。安装完成后仍需实际检查游戏内面板、登录和播放，不会将文件部署成功描述为播放测试通过。

## 遇到问题

- **找不到目录**：在 Steam 的游戏管理菜单中浏览本地文件，选择那个文件夹。
- **游戏还在运行**：正常退出后重新扫描。管理器不会结束你的游戏进程。
- **安装包校验失败**：重新完整解压原始包。不要从别人的游戏目录复制插件或账号文件。
- **完整 ChillPatcher 或重复插件冲突**：先在原来的工具中停用或整理重复文件。管理器不会擅自停用不认识的 Mod。
- **不同或缺失的共享框架**：先处理现有 Mod 框架，再尝试安装；管理器不会覆盖不同版本的加载器。
- **停用后恢复**：选中平台点击“重新启用”。有缺失文件时先安装 / 修复。
- **想回到上次操作前**：点击“撤回上次操作”。如果文件后来被手动修改，管理器会停止撤回，保留修改。
- **按快捷键没反应但文件检查通过**：确认选中了正在运行的那份游戏目录；游戏更新、其他 Mod 和运行时问题仍需结合游戏内结果及 BepInEx 日志排查。管理器不会自动读取或上传账号日志。

账号、歌单、本地歌曲索引和游戏存档均不会被管理器打包、上传或清除。每个平台的原说明和第三方许可证位于 `packages/<平台>/`。

## 备份和撤回范围

每次修改前，把本平台将涉及的已存在插件二进制和安装记录备份到游戏目录 `.chill-music-manager/<平台>/`。撤回前会检查备份和当前文件的 SHA256。被替换或移走的二进制保留在操作目录中，不清空历史备份。

“撤回上次操作”只针对该平台最近一次由本管理器完成的操作。既有安装器生成的旧备份继续保留，但本版不提供任意历史版本选择。初次安装后撤回，新增的插件会停用并移出加载目录，共享 BepInEx 框架保留，避免影响其他 Mod。

更新和停用不修改 `account`、`library`、原音乐、游戏存档或其他插件配置。安装和修复沿用各平台安装器的备份及失败恢复逻辑，额外增加管理器层的文件恢复。并发管理器操作会被目录锁阻止。

## 环境与验证

Windows x64，Windows PowerShell 5.1 和 .NET Framework 4.5 或更新版本。系统需具备原插件要求的媒体组件。本版为 Windows 管理器；尚未适配 Steam Deck、Linux 或手机版。

本次完成的隔离测试见 `TESTING.md`，原始结果见 `tests/test-results.json`。本次没有在真实游戏目录执行安装，也没有重新进行六个平台的登录与音乐播放测试。

## 源码

- `source/ManagerWindow.cs`：Windows 图形界面。
- `Manager.ps1`：扫描、校验、操作锁、部署和撤回逻辑。
- `catalog.json`：随包版本、运行文件及安装目标的 SHA256。
- `packages/`：六个现有发行包，保留源码、离线依赖与许可证。
- `tests/Tests.ps1`：在独立临时目录运行安装生命周期与保护检查。

运行 `Build.ps1` 可用 Windows 自带 .NET Framework C# 编译器重建管理器。测试可在 PowerShell 中调用 `tests/Tests.ps1 -Package <完整解压后的管理器目录>`。测试会在 tests 下建立独立目录，不修改真实游戏。
