# v1.3.0-rc.1 验证记录

本合集将五个平台的真实播放记录候选更新与 v1.2.0 游戏风格面板合并。网易云使用已发布候选包中的同一 DLL；QQ、酷狗、B站与喜马拉雅保留合集主题后重新编译。椒盐与进度插件逐文件核对，保持 v1.2.0 原文件。

## 本次执行

- 四个平台插件使用本机游戏和 BepInEx 引用程序集编译成功，管理器 WinForms 编译成功；部分游戏 Newtonsoft.Json / netstandard 引用存在统一版本警告。
- 管理器 21 组隔离回归通过，覆盖七插件共存、目标 SHA256、安装记录版本、启用/停用/撤回、依赖修复、拒绝降级、冲突、文件锁、备份损坏、目录链接、游戏运行保护、无效目录以及真实 WinForms 渲染。结果在 `tests/test-results.json`。
- 五个联网平台分别从旧合集升级再撤回，核对插件、原生桥接 DLL、安装记录以及原先停用状态恢复；合成账号标记、配置和本地播放进度不变。网易云更新未启用已停用的 QQ 插件。结果在 `tests/upgrade-result.json`。
- 安装中途制造写入失败，检查先前被修改的文件恢复并报告失败。结果在 `tests/recovery-result.json`。
- 修正酷狗和 B站安装器写入旧版本号的问题；重新执行安装记录检查。
- 校验完整离线文件目录、各包 SHA256、所有压缩包 CRC 和最终 ZIP 校验值。完整包不含用户账号、登录缓存、游戏存档、日志或用户音频。

`preview.png` 为本次 WinForms 的真实渲染，显示隔离测试目录。`tests/theme/`、`tests/history/` 和椒盐/进度包内旧结果均为历史资料，未在本次重新执行。

## 播放记录证据与限制

五个平台的计时和协议测试已在各自候选包发布前完成，结果见各包 `TESTING.md` 与 `PLAYBACK_REPORTING.md`。本次合并没有更改它们的计时或上报业务实现，只调整四个平台的主题 UI、保留错误恢复入口，并更新两份安装记录版本。

网易云独立候选版此前在真实游戏中确认开始记录和一次实际播放 178 秒的结束记录成功提交。该证据不代表账号时长、等级或年报已经入账。其他平台以及新版合集未完成真实账号入账验证；酷狗同步真实秒数增量，未实现 CSCC 单曲播放历史。

本次没有更新或启动用户真实游戏，也没有重新扫码、验证全部平台播放或验证 Unity 内最终界面。个人游戏仍仅保留原先启用的网易云。本版因此作为预发布候选版，稳定 Latest 不变。

如需重跑完整管理器测试，使用 PowerShell 7；安装器子进程使用 Windows PowerShell 5.1。升级检查必须传入旧版完整合集，且只使用合成标记，不使用真实账号。
