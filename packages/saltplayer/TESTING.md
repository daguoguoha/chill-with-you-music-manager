# 歌词、透明显示和播放会话验证

- 六个平台均对本机游戏、BepInEx 与 Unity 程序集编译成功；同此前版本，游戏 Newtonsoft.Json / netstandard 引用存在统一版本警告。
- 32 项 LRC/本地导入检查通过，包含时间戳边界、前后跳转、多时间戳、翻译、offset、空白间隙、编码、大小限制、取消和缓存隔离。
- 22 项真实播放位置集成检查通过，覆盖暂停不随墙钟推进、快进/后退、旧请求迟到、单任务限制、跨平台切换、V 键防连发、输入和组合键防误触。使用可控音频替身和生产集成代码。
- 22 项会话存储/颜色检查、21 项启动恢复集成检查通过，覆盖曲目和队列恢复、实际音频帧确认进度、暂停状态、慢速登录等待、原生曲库初始化、空曲库过渡、手动选歌优先、原游戏音乐、最近平台、并发写入和正常退出保存。
- 管理器 21 组安装生命周期回归通过；六个平台从 v1.3.0 合集更新并撤回，账号、配置、歌词与音频进度测试标记保留；安装中途失败恢复检查通过。
- 网易云和 QQ 的匿名公开歌词样例返回了带时间轴的歌词。酷狗公开搜索在当前网络返回空响应，不能视为自动获取已验收；保留准确 hash 查询和 LRC 导入。
- 网易云初版歌词已在本机真实游戏中显示，用户确认显示、同步、暂停、进度、切歌、隐藏和设置正常。后续透明、V、拖动、颜色和启动恢复的最终游戏验收另记在 `tests/lyrics/runtime-result.json`。

隔离测试不能代替各平台真实账号验收。其他五个平台的新界面和自动启动流程尚未逐一进行游戏内验收。本版按候选版发布；播放记录时长入账验证限制沿用上一候选版，未声称等级或年报已累计。

本版业务播放/登录/解码和播放记录协议沿用旧版，新增代码位于 `Lyric*.cs`、`PlaybackSession*.cs`。原生桥接及离线依赖不变。包内不会包含用户歌词、播放会话、账号或游戏日志。
