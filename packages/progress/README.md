# 音频进度保存 v1.0.0

在 Chill 音乐插件管理器 v1.1.0 中选中“音频进度保存”，点击“安装 / 修复至随包版本”，正常启动游戏即可使用。它与六个平台插件分别安装和停用。

支持网易云、QQ 音乐、酷狗、B站音频、喜马拉雅、椒盐 / 本地音乐插件生成的音轨。每个音轨分别记录秒数，每 5 秒写入一次；暂停、拖动进度、切歌、失去焦点和正常退出时也会保存。再次点播同一个音轨时，从上次位置继续。不会自动登录、重新导入歌单或打开游戏就自动播放。

退出后先按原平台的使用方式打开相同专辑或歌单，再点播上次的音轨。网络平台仍需要原有的网络与账号权限。换了源文件或音频时长明显变化时，旧续播点会被忽略。

播放不足 3 秒、剩余不超过 5 秒或自然播放完成时，从头播放。完成回调在单曲循环和自动下一首之前清除记录，避免反复播放结尾。拖到开头后也会清除旧位置。游戏强退或断电时，通常最多损失最近一次成功保存后的数秒进度；磁盘写入失败时无法保证这一时间。

记录只保存在游戏目录 `BepInEx/config/ChillAudioProgress/progress.json`，包括带平台前缀的音轨标识、秒数、总时长和更新时间，不记录账号凭据、音频内容、标题或播放地址，不上传到网络。最多保留 2000 个音轨。使用临时文件和原子替换写入，上一份保存在 `.bak`；损坏的原件会重命名保留。新版本格式不被旧插件覆盖。

配置文件为 `BepInEx/config/local.chill.audioprogress.cfg`。`Progress.Enabled` 控制记录功能，`Progress.ResumeOnPlay` 可单独关闭自动续播。首次运行后生成。修改前退出游戏。

管理器中的停用、更新和撤回操作保留进度文件。若要清空历史，退出游戏后将 `ChillAudioProgress` 配置目录移到其他位置备份，再启动游戏。清空记录不需要删除其他插件的账号或游戏存档。

`Build.ps1 -GameDirectory <游戏目录>` 编译插件，只读取游戏程序集，将 DLL 输出到当前源码包的 BepInEx 目录。不会向游戏目录部署。需要游戏及 BepInEx 5 的引用程序集，这些游戏文件不随源码分发。GPL-3.0-or-later，第三方 BepInEx 依赖保留其原始许可证。

本版通过了进度存储与播放器适配层的隔离测试，使用替身模拟 Unity 播放对象。已对本机游戏程序集完成真实编译和接口检查，尚未在真实游戏里播放、退出、重启验证。隔离测试不能代替游戏内验收。
